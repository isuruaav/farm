# Generated catalog product photography

Created on 20 November 2026 with the built-in `image_gen` tool. Twenty individual product photographs replace the previous drawings on product cards, product detail pages, quick views, related products and homepage featured cards. Images are illustrative generic product and packaging concepts.

Each final WebP is 1200 × 800 pixels. The complete set is about 1.88 MiB. New `assets/images/products/photo-v2/` paths avoid the previous images' browser cache. Original JPEG assets remain available.

The live SQLite catalog, `data/products.json` seed images and SKU fallback paths in `includes/bootstrap.php` use these files. Only live product image paths and modification timestamps changed; business fields were checked against the preceding records. Source backups are in `storage/backups/pre-product-photography.zip`; the consistent database backup is `storage/backups/pre-product-photography.sqlite`. These backups remain protected from public HTTP access.
